# Changelog

All notable project changes will be documented here.

## [0.0.1] - 2026-10-08

### Added
- Installable Python project and Windows setup/launch scripts.
- PySide6 desktop window with a welcome screen and empty project placeholder.
- File, Edit, View and Help menus; working New/Exit/About actions.
- Disabled Open/Save/Undo/Redo commands until implemented.
- Optional status bar visibility and window geometry persistence.
- Small core model for an in-memory project session (not yet a musical score).
- C++17 / CMake starter library and native smoke test.
- Python unit tests and Windows GitHub Actions CI.
- Architecture notes and contribution guidelines.

### Not included yet
- Editing musical notes, saving project files, opening MIDI, PDF/MusicXML conversion,
  audio playback, AI transcription. These are roadmap items, not current features.
